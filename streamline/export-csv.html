Export CSV Export iteration work items from Jira
NOTE: Data Accuracy:
Timing is essential
The Scrum Master needs to identify the point in time that the sprint ends. To avoid noise in the exported data, it is essential to run this export at this time.

Example: When Jira sprint end date differs to time that new sprint is actually kicked off.


Risk of Inaccuracy
The further from the point in time that the export happens the higher the risk of inaccuracy in the data, especially if there are items that carry over into the next sprint.


Acknowledged Limitation
This is an acknowledged limitation of this metrics automation technique/tool which is based on this manual csv export.

As an alternative, consider more complex metrics solutions.
step 1:
Find work items
In jira, search for all work items in your iteration using issue search.


JQL Search Query
project = 'ABC' AND sprint=1234 ORDER by created DESC


To find the sprint ID:
  • Open one of the sprint reports like sprint report.
  • Check that the appropriate sprint is selected.
  • Copy the number at the end of the url.
